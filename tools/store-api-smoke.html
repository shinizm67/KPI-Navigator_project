このページ（smoke）に戻る方法
  1. アドレス欄にこれを貼る（いちばん確実）:
    http://127.0.0.1:8080/tools/store-api-smoke.html
  2. 同じタブで開いた場合 → ブラウザ左上の ← 戻る
  3. タブが残っている場合 → Store API smoke のタブをクリック

※ Monthly / Annual 側には「smokeへ戻る」ボタンはありません。上の方法で戻ってください。

—

次にやること（ここまでできたら）

  1. 上の GET / PUT / Enable sync が成功している（もうOKならそのままで大丈夫）
  2. — smoke のままサーバ内容をノートにコピー（Annual を開かなくても可）
  3. — 取り込めたか確認
  4. Annual を開く（同じサイト） — 開いたら、上の「smokeに戻る方法」で戻る → 「ノートを見る」
  5. Monthly を開く（同じサイト） — 別ページでも同じノートか確認。戻ったら「ノートを見る」

いまの確認：同期OFF（ローカルだけ）

  1. を押す
  2. 緑で「同期OFF」と出たらOK
  3. そのあと
  4. 灰色の箱で "enabled": false なら成功（ノートの数字は残っていて大丈夫）

次の確認：別の窓でも同じノートか

これは「別の人が同じロッカーを開ける」テストです。同じタブではダメで、シークレット（プライベート）ウィンドウを使います。

  1. いまの窓で → の順（ロッカーに最新を入れる）
  2. Chrome ならメニューから 新しいシークレットウィンドウ（Safari ならプライベート）を開く
  3. 新しい窓のアドレス欄にこれを貼る:
    http://127.0.0.1:8080/tools/store-api-smoke.html
  4. 新しい窓だけで: Enable sync → （必要なら）Annual を開く → ノートを見る
  5. 新しい窓でも緑の「OK: …3633」なら成功

※ 新しい窓は最初はノートが空です。同期ONにするとロッカーからコピーされます。

※ 同期ONのときは、サーバの内容がブラウザのノートに入ります（テスト用サンプルに上書きされることがあります）。

※ Annual / Monthly / smoke は同じ「8080の家」なので、ノート（メモ）も共通です。
