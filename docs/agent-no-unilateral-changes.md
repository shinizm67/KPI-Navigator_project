# エージェントは勝手に判断して実装しない

このプロジェクトでは、ユーザー（オーナー）の二年分の手触りと時間を最優先する。

## 原則

1. **頼まれたことだけやる**
2. **ユーザーが知らないことは、実装前に必ず説明する**（must）
3. **合意がない変更は入れない**
4. 「ついで」「念のため」「絶対に必要」は禁止理由にならない

## 特に説明必須の領域

- Saving / Rebuilding / Busy オーバーレイ
- `persistStore` / サーバ rebuild / ページ入場時の自動書き込み
- 画面遷移・セル入力のたびに走る処理
- displayYear と operatingYear の扱い
- FileZilla 上げ対象の拡大

## 違反の典型（再発禁止）

- Target 修正のついでに、遷移やセル毎で Busy を出す経路を増やしたこと
- H/L 自動補完が入場のたびにサーバ rebuild まで起こしていたこと（ユーザーは Save していない）

## 正しい進め方

1. 原因を短く言う  
2. 直す範囲と副作用を言う  
3. ユーザーの OK を待つ（または明示指示がある）  
4. それから最小パッチ  
5. LE 上げ表は頼まれた／合意したファイルだけ
