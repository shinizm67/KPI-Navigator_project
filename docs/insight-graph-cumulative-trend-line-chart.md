# Insight Graph — 累計推移折れ線グラフ（Cumulative Trend Line Chart）

更新日: 2026-05-19

Graph タブの **Monthly**（将来は Annual 等でも同一仕様）に置く、**累計目標推移 vs 累計実績推移** の折れ線グラフ。Daily / Monthly / Annual の Insight オーバーレイで **サイズ・色・幾何はすべて共通** とする。

実装の参照先: 4 ファイル（`app/monthly`, `en/app/monthly`, `app/annual`, `en/app/annual` の `index.html`）。クラス接頭辞 `insight-graph-monthly-trend`（Annual Graph に載せる場合も同クラス・同寸法）。

## Y 軸ラベル（金額）

| 項目 | 値 |
|------|-----|
| フォント | **13px** |
| 色 | `#58E1F3` |
| 配置 | Y 軸の**左側**、各目盛の高さに `text-anchor: end` で右寄せ |
| 目盛数 | **5 分割**（Figma 同様、0 を含む 5 ラベル） |

**スケール（実装ルール）**

- 縦軸は **その月の累計目標・累計実績の最大値** から自動スケール（固定の `$15,000` 表示はモック用）。
- 店舗の日次売上が ¥150,000〜¥300,000 / ¥1,000,000 などまちまちでも、**累計の最大に合わせて nice tick**（きりの良い刻み）で 5 分割。
- **EN**（`en/` ページ）: **`$` 表記**。桁感は JP より概ね 2 桁少ない想定で、同じ数値ロジックに **通貨記号と locale のみ** 差し替え。
- **JP**: **`¥` 表記**、`ja-JP` locale。

## X 軸ラベル（日）

| 項目 | 値 |
|------|-----|
| フォント | **13px** |
| 色 | `#58E1F3` |
| 配置 | X 軸の**下側**、目盛 X にセンター |

**仕様**

- **月次**: 日 **1 〜 月末**（28 / 29 / 30 / 31 はフォーカス月に依存）。
- ラベルは Figma 同様 **約 7 点**（1 日、ほぼ等間隔、**最終日 = 月末**）。例: 31 日月 → `1, 5, 10, 15, 20, 25, 31`。

## 折れ線（KGI / KPI）

| 系列 | 色 | 備考 |
|------|-----|------|
| Cumulative Actual Trend (**KGI**) | `#58E1F3` | 実績累計。当日までの日のみ描画可 |
| Cumulative Target Trend (**KPI**) | `#FF0000` | 目標累計。通常は月初〜月末の直線（線形累計） |

線幅 **2px**（実装デフォルト）。終点付近の金額ラベルは Figma どおり折れ線色と同系色で HTML オーバーレイ可。

## ホバーツールチップ（プロット領域内・交差点ヒット）

### 発火条件

- マウスが **プロット矩形（800×400）内**にあること。
- X を最も近い **日** にスナップしたうえで、その日の **KGI または KPI 線上の点** まで距離が **14px 以内**（どちらか近い方）。
- 条件を満たさないときは **ポップアップ非表示**（グラフ外・余白・線から離れた位置では出さない）。

### ホバー時の表示

- **縦補助線**（スナップした日の X、点線・シアン）
- **◯マーカー**（ヒットした系列の色: KGI=`#58E1F3` / KPI=`#FF0000`、半径 6px）
- **ポップアップ** 400×240（交差点付近にオフセット、枠端でクランプ）

### ポップアップ仕様

| 項目 | 値 |
|------|-----|
| サイズ | **400×240px** |
| 枠 | 1px `#0F9403`、背景 `#1E1E1E` |
| 日付 | 14px **Bold**、中央、`#58E1F3`（例 `2026.5.22 fri`） |
| 4 行 | 14px Regular、ラベル左・値右 |
| ラベル位置 | 外枠左 **22px**、1 行目上 **64px** 起点 |
| 値位置 | 外枠右 **22px**、1 行目上 **64px** 起点 |
| 行間 | **34px**（14px 行高 + 20px margin） |
| ラベル末尾 | 半角スペース + `:`（例 `Today's Sales :`） |

| 行 | EN ラベル | JP ラベル |
|----|-----------|-----------|
| 1 | Today's Sales : | 本日の売上 : |
| 2 | Today's Target Sales : | 本日の目標売上 : |
| 3 | Difference : | 差額 : |
| 4 | Achievement : | 達成率 : |

表示値はその日の **日次** 売上・目標・差額・達成率（累計ではない）。実装: `initGraphMonthlyCumulativeTrend`。
