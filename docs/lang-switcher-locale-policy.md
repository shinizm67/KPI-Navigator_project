# 右下言語スイッチャー（ロケール別）

日常の切替はほぼ起きない前提で、右下のショートカットは **実際に使う選択肢だけ** にする。

## 仕様

| 現在ページの `html[lang]` | 右下 `#lang-select-wrap` |
|---------------------------|--------------------------|
| `ja` | **JP / EN** のみ（TW 非表示） |
| `zh-TW`（および `zh*`） | **TW / EN** のみ（JP 非表示） |
| `en` | **表示（EN から母語ページへ戻れるようにする）** |

### 理由

- 一度設定したらほぼ変えない
- 非英語ユーザーが説明目的で一時的に英語へ切替後、母語ページへ戻る導線が必要
- 母語ユーザーの実務上の切替は **母語 ↔ 英語** が中心
- 日本語ユーザーが台湾語へ、台湾語ユーザーが日本語へ、の切替はほぼ起きない

### 例外（フル選択を残す場所）

- **Preferences（設定）の「言語を選択」`<select id="pref-lang">`** は、初回・明示的な言語変更用として **JP / EN / TW をすべて表示** する（右下ショートカットとは役割を分ける）。

## 実装

- CSS: `html[lang=…]` に応じて `.lang-option-*` を表示制御（`#lang-select-wrap` 自体は常時表示）
- マーカー: `KPI-LANG-SWITCHER-LOCALE`（各 HTML の `<head>` 内）
- 適用スクリプト: `scripts/apply_lang_switcher_locale_filter.py`

## 非対象

- Focus Bar 製品名などの英語表記方針とは別件
- フォント方針（`docs/font-locale-policy.md`）とは別件
